# 발전량 점검 (eda)

담당: 김준영 (기준선·집합자원 최적화)

정답 데이터(발전량)에 이상한 값이 없는지 확인한 스크립트입니다.
결과를 바탕으로 이주영님 데이터 v0.1의 처리 방침 후보 중 발전량 관련 항목(1~4번, 11번)을 검토했습니다.

## 파일

| 파일 | 확인하는 것 | 결과 저장 |
| --- | --- | --- |
| `gen_quality.py` | 발전소별 기록 기간, 중간 누락, 음수, 낮인데 0, 하루 종일 0, 최대 이용률 | `outputs/gen_quality.csv` (로컬 전용) |
| `night_check.py` | 밤인데 발전량이 있는 행: 태양 고도를 정각 기준 vs 구간 중앙 기준으로 비교, 깊은 밤 양수가 몰린 발전소 | 화면 출력만 |
| `pv240_check.py` | 깊은 밤 양수가 몰린 발전소(PV240)의 시각 어긋남 여부와 값 크기 확인 | 화면 출력만 |
| `check_generation_data.py` | 팀 공통 데이터(이주영님 train_vX)의 발전량 처리가 합의대로인지 원본에서 다시 계산해 확인 (14개 항목). 새 데이터 버전이 나올 때마다 실행 | 화면 출력만 |

## 실행

레포 최상위 폴더에서 실행합니다.

```
python eda/gen_quality.py
python eda/night_check.py
python eda/pv240_check.py
python eda/check_generation_data.py data/data_v0.4/train_v0.4.parquet   # 데이터 경로는 버전에 맞게
```

## 주요 결과

- 발전소마다 기록 시작 시점만 다르고(2021년 31개 ~ 2024년 105개), 시작 이후 누락은 최장 8시간
- 음수 40행: 값 −1 ~ 0, 새벽·저녁에만 발생 → 대기전력
- 하루 종일 0인 날이 10일 넘는 발전소 13개 → 고장·출력제한 추정
- 최대 이용률 0.81 ~ 1.03 → 용량 정보 정상
- 야간 판정은 구간 중앙(ts − 30분) 기준이 더 정확 (밤 양수 163,789 → 144,031행)
- 남은 밤 양수는 해 뜨기 직전·진 직후의 실제 미세 발전 (발전량 비중 0.1%)
- 깊은 밤 양수 1,217행 중 1,200행이 PV240. 모든 달에서 시각 어긋남 없음, 값은 최대 1kWh(용량 대비 0.1%)인 계량기 미세값

## 공통 데이터 확인 결과 (11/5, v0.4)

- `check_generation_data.py` 14개 항목 모두 통과
- 행은 원본 발전량 행 그대로(4,392,566행), 음수는 0으로·원본 보존, 이용률 상한 1.2, 하루 종일 0 판정(714개 발전소·일), 야간 판정(구간 중앙 기준) 모두 합의대로
- 11/3 합의 반영: `use_train` = 낮 & 하루 종일 0 아님 (학습 2,181,071행). 점수 계산은 모든 행
- 점수 코드(`scoring/score.py`)의 정답 = 공통 데이터 `energy_kwh`
- `split` 경계 = 11/4 확정 기간, 검증·최종 검증은 253개소 × 모든 시각 꽉 참
