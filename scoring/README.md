# 공통 점수 계산 (scoring)

담당: 김준영 (기준선·집합자원 최적화)

대회 정산식을 그대로 구현한 팀 공통 채점 코드입니다.
주최 측이 채점 코드(scoring.py)를 배포하지 않아서 직접 만들었습니다.
모델·그룹 배정을 바꿨을 때 같은 기준으로 비교하는 용도입니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `score.py` | 점수 계산 함수 모음 (채점, 벌금 분석, 배정 검사) |
| `score_file.py` | 예측 파일만 넣으면 실제값을 붙여 채점하는 실행 파일 |

## 계산식

```
정산금 S = Σ SMP × 실적 − 0.10 × Σ SMP × k × |예측 − 실적|
```

- 그룹별·시각별로 발전소 예측과 실적을 먼저 합산한 뒤 계산
- k: ts의 시가 11~15이면 3, 아니면 1 (train/smp.csv에는 k가 없어 규칙으로 생성)
- 오차 정의: 예측 − 실제 (팀 공통 규칙)
- 실적의 음수는 0으로 처리

## 사용법

레포 최상위 폴더에서 실행합니다.

```
python scoring/score_file.py 예측파일.csv                 # 기본 배정(A→G1, B→G2)으로 채점
python scoring/score_file.py 예측파일.csv 배정파일.csv     # 지정한 배정으로 채점
```

| 입력 | 필요한 열 |
| --- | --- |
| 예측 파일 (csv 또는 parquet) | `site_id, ts, pred_kwh` |
| 배정 파일 (선택) | `site_id, group` (G1/G2) |

- 예측 파일에 들어 있는 기간을 채점합니다.
- 그 기간에 실적이 있는 (발전소, 시각)은 전부 예측이 있어야 합니다.
- 중복, 음수, 빈 값, 무한대가 있으면 오류로 알려줍니다.
- 시각은 타임존이 있는 형식 (예: `2025-03-01 01:00:00+09:00`)

**출력:** 정산금 S, 벌금, 가중치 없는 절대오차 합(동점 처리용)

## score.py 주요 함수

| 함수 | 설명 |
| --- | --- |
| `score(site_preds, composition, smp)` | 실제값·예측값이 함께 있는 표로 채점 |
| `score_preds(preds, composition, data_dir)` | 예측값만 있는 표로 채점 (실제값 자동 연결) |
| `breakdown(...)` | 벌금이 어느 달·어느 가중치 시간대에서 나왔는지 비율 |
| `check_composition(composition, sites)` | 배정 검사: 253개 중복·누락, G1/G2 이름, 각 그룹 20,000kW 이상 |

## 검산

- `python scoring/score.py` 실행 시 작은 예제 검산
  - 13시(k=3), SMP 100원, 발전소 2개 오차 +100 / −100kWh
  - 같은 그룹: 벌금 0원 / 다른 그룹: 벌금 6,000원 → 손계산과 일치
- 같은 예측을 두 경로(`score`, `score_preds`)로 채점해 결과 일치 확인
